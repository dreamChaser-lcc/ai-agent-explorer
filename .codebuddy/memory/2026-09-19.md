## 路线 A（tcpSocket 探针）实战完成

1. 基线实验（无探针）：`rollout restart deployment/gateway` + curl 循环 → 观测到 `000`（真实中断）；
2. 加探针：重写 `~/k8s-lab/micro-lab.yaml` v2（三个 Deployment 均加：readiness tcpSocket [initialDelay 5 / period 5 / failureThreshold 6]；liveness tcpSocket [40 / 10 / 5]），旧版备份为 `micro-lab.yaml.bak-noprobe`；
3. 对比实验：**探针后全程 200，零中断滚动更新验证通过** ✅
4. 观察特征：新 Pod 经历 `0/1 Running → 1/1 Running`（未就绪窗口可见）。
- 参数黄金法则：**liveness 容忍时间必须 > 应用最长启动时间**（否则误杀 → CrashLoopBackOff）；readiness 失败不重启只摘流量，参数可从宽。
- 关键认知：探针定义在 Pod spec（Deployment YAML）里、**与镜像无关**——本次改动零成本，无需重建镜像。
