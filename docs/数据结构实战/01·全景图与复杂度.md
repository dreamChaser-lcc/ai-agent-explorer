## 一、一切数据结构的三个基本问题

```text
① 存哪？（内存布局：连续 or 分散）
② 怎么找？（查找复杂度：O(1) / O(log n) / O(n)）
③ 怎么变？（插入删除的代价：搬多少数据 / 调多少指针）
```

**每个"新"结构都是为了优化其中一项**：

```text
数组     → 换来了 O(1) 随机访问
链表     → 换来了 O(1) 插入删除
哈希表   → 换来了平均 O(1) 查找
BST      → 换来了 O(log n) 有序查找
红黑树   → BST 加了"防退化"保险
B+ 树    → 红黑树思想搬到磁盘（为 IO 优化）
```

## 二、复杂度速查总表（主角表，先睹为快）

| 结构 | 查找 | 插入 | 删除 | 备注 |
|---|---|---|---|---|
| 数组（无序） | O(n) | O(1) | O(n) | 末尾插快 |
| 数组（有序+二分） | O(log n) | O(n) | O(n) | 插删要搬家 |
| 链表 | O(n) | O(1)* | O(1)* | *已知位置时 |
| 哈希表 | 平均 O(1) | 平均 O(1) | 平均 O(1) | 最坏 O(n)（全撞一个桶） |
| BST（退化） | O(n) | O(n) | O(n) | 顺序插入变链表 |
| BST（平衡） | O(log n) | O(log n) | O(log n) | — |
| 红黑树 | O(log n) | O(log n) | O(log n) | 旋转最多 2 次 |
| B+ 树 | O(log n) 次IO | O(log n) | O(log n) | 树高 3~4 层 |
| 堆（查最值） | O(1) 堆顶 | O(log n) | O(log n) | 任意查找是 O(n) |
