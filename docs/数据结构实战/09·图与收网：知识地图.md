## 三、一张"为什么是它"的因果网

```text
要 O(1) 随机访问 → 数组
要 O(1) 头尾增删 → 链表
要 O(1) 按键查找 → 哈希表（代价：无序、碰撞、rehash）
要有序 + O(log n) → BST → 会退化 → 红黑树（内存）/ B+ 树（磁盘）
要"最值"快速可得 → 堆
内存磁盘之争：红黑树节点在内存（快）；磁盘按页读 → 节点越大越好 → B+ 树
```

## 一句话

```text
所有结构都是"用代价换能力"的交易链：
数组→链表→哈希→BST→红黑树→B+树，每一环都在补上一环的短板
工程选型 = 看你的场景最在乎哪项能力
```
