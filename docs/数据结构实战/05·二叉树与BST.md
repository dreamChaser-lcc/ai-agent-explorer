## 一、树的名词卡（先统一黑话）

```text
        A          ← 根（root）
       / \
      B   C        ← A 的孩子（child）；A 是它们的父（parent）
     / \   \
    D   E   F      ← D/E/F 没有孩子 = 叶子（leaf）

度：一个节点的孩子数（B 的度=2，F 的度=0）
深度：从根往下数（D 的深度 = 2）
高度：从叶子往上数（树高 = 从根到最深叶子的层数）
二叉树：每个节点最多 2 个孩子的树
```

---

## 二、四种遍历（心智模型：递归）

```text
前序（根左右）：A B D E C F     —— 先看自己再看子孙（复制树）
中序（左根右）：D B E A C F     —— BST 中序 = 排序结果！（重要性质）
后序（左右根）：D E B F C A     —— 先处理子孙再处理自己（删树/算目录大小）
层序（BFS）：A B C D E F        —— 一层一层（队列实现）

口诀："前中后"说的是【根】在什么时候被访问
```

---

## 三、BST 二叉搜索树：会排序的树

```text
规则：左子树所有节点 < 根 < 右子树所有节点（对每个节点都成立）

            50
           /  \
         30    70
        /  \     \
      20    40    80

查找 40：50 → 左（40<50）→ 30 → 右（40>30）→ 40 命中
= 每层砍掉一半 → O(log n)
```

## 四、致命弱点：退化（一切平衡树的动机！）

```text
按顺序插入 10, 20, 30, 40, 50：

  10                    BST 的规则没被违反，
    \                    但树变成了"链表"——
     20                  查找退化回 O(n)
       \
        30               这就是"不平衡"
          \
           40
            \
             50

★ 记住这个画面：[红黑树（06）](06·平衡树：AVL与红黑树.md) [网页版](https://github.com/dreamChaser-lcc/ai-agent-explorer/blob/main/docs/数据结构实战/06·平衡树：AVL与红黑树.md) / [B 树（08）](08·B树与B+树.md) [网页版](https://github.com/dreamChaser-lcc/ai-agent-explorer/blob/main/docs/数据结构实战/08·B树与B+树.md) / 跳表 都是为了治这个病而生的
```

**退化什么时候发生**：插入顺序接近有序（自增主键、时间戳做 key——业务里太常见了）。

## 五、工程落点

| 落点 | 说明 |
|---|---|
| BST 本身 | JDK 没有——因为会退化，直接上了红黑树 |
| TreeMap/TreeSet | 红黑树实现的"有序 BST"（06 课） |
| 中序遍历性质 | 数据库索引的"有序性"本质（08 课 B+ 树叶子链表） |

## 一句话

```text
BST = 左小右大的二叉树：查找 O(log n)，中序遍历得升序
致命弱点：顺序插入退化成链表（O(n)）
——接下来两课的全部内容都是在治这个病
```
