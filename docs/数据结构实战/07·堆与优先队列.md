# 07 · 堆与优先队列

## 一、结构定义（两句话）

```text
① 完全二叉树（除最后一层全满，最后一层靠左）
② 父节点 ≤/≥ 孩子们（小根堆：父最小；大根堆：父最大）

注意：堆只管"父子之间"的偏序，兄弟之间无约束
     ——所以堆顶最值 O(1)，但任意查找是 O(n)
```

---

## 二、数组存储的巧妙（不用指针！）

```text
         1                 数组：[1, 3, 2, 8, 5, 6]
       /   \
      3     2             下标公式（从 0 开始）：
     / \   /                父(i) = (i-1)/2
    8   5 6                 左孩子(i) = 2i+1
                            右孩子(i) = 2i+2
完全二叉树的性质让数组下标天然对应树结构——零指针开销
```

---

## 三、两个核心操作

```text
上浮（siftUp）——插入后：
  新元素放数组末尾 → 跟父比 → 比父小（小根堆）就交换 → 直到不小于父
  O(log n)

下沉（siftDown）——删堆顶后：
  末元素补到堆顶 → 跟较小的孩子比 → 大就交换 → 直到比两个孩子都小
  O(log n)
```

## 四、经典应用：Top K 问题（面试高频）

```text
"10 亿个数找最大的 100 个"：
  维护一个 100 容量的小根堆（堆顶 = 100 个里最小的）
  新数 > 堆顶 → 弹堆顶、进新数
  扫完剩下的数 → 堆里就是 Top 100
  复杂度：n × log 100 ≈ n × 7 —— 内存只要 100 个数

Java 一行版：
new PriorityQueue<Integer>(100, Comparator.reverseOrder())  // 大根堆
```

## 五、工程落点

| 落点 | 说明 |
|---|---|
| `PriorityQueue` | 默认小根堆；构造器传 Comparator 换大小 |
| 定时任务调度 | 按到期时间的小根堆（下一个该跑的总在堆顶） |
| Dijkstra 最短路 | 每次取"当前最短距离"的节点 = 小根堆 |
| 线程池 priority workQueue | 任务按优先级出队 |

## 一句话

```text
堆 = 完全二叉树 + 父子偏序 + 数组下标公式（零指针）
只保证"最值 O(1) 可得"——不是搜索树
Top K = K 容量对顶堆，n log K 扫一遍
```

## 图说话速览：堆 = 数组装的完全二叉树（2026-10-30 学员需求）

### 一、结构全景

```text
逻辑（完全二叉树）：          物理（一个数组）：
        1                     idx: 0  1  2  3  4  5  6
      /   \                  val: [1][2][3][4][5][6][7]
     2     3                 没有指针！父子关系靠算术算
    / \   / \                parent(i)=(i-1)/2  left=2i+1  right=2i+2
   4   5 6   7
```

**小顶堆铁律**：爹 ≤ 两个娃（只保证父子，不保证堂兄弟——所以数组不是有序的）

### 二、push 流水线（上浮 siftUp）

```text
插 4 到 [1,2,3]：末尾追加 [1][2][3][4]
  i=3: parent=1(值2)，2 > 4 ✓ 停（若 4<2 则交换继续向上）

插 0：
  [1][2][3][4][0] → 0<2 换 → [1][2][0][4][3] → 0<1 换 → [0][1][2][4][3]
  只 2 次交换 = O(log n)
```

### 三、pop 流水线（下沉 siftDown）

```text
取走根 [0]，末尾 [3] 顶上 → [3][1][2][4]
  和【较小的娃】比：left=1(值1) < 3 → 换 → [1][3][2][4]
  i=1: 娃 4 > 3 ✓ 停
代价 O(log n)，不是 O(n) 重排
```

### 四、Top K（10 万找前 10 大）

```text
维护大小 K=10 的小顶堆：来一个比堆顶大就替换+下沉
O(n log K) = 10万×4 次比较；内存只存 10 个
——"从 100GB 日志找前 10"的标准答案
```
