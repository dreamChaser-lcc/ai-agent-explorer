## 一、为什么学 ES（你其实已经"用过"搜索）

```text
前端本地搜索 = arr.filter(x => x.title.includes(kw))     —— 数据小，随便写
数据长大后：
  · 全表扫描 O(n) → 百万行就卡
  · "数据库"搜不到"数据 库"    → 没有分词
  · 只分"匹配/不匹配"          → 没有相关度排序
  · 同义词/拼音/模糊全部做不到

ES 就是这些问题的标准答案——"关键词秒搜亿级数据"的工业级方案。
```

```text

```

## 六、环境准备（到阶段 2 时再配）

```powershell
# Elasticsearch（单节点，8.x；学习环境关安全校验）
docker run -d --name es -p 9200:9200 -e discovery.type=single-node `
  -e xpack.security.enabled=false elasticsearch:8.15.0

# Kibana（DevTools 控制台 = ES 的"浏览器 DevTools"）
docker run -d --name kibana -p 5601:5601 --link es -e ELASTICSEARCH_HOSTS=http://es:9200 kibana:8.15.0
#   ES REST:  http://localhost:9200
#   Kibana:   http://localhost:5601（DevTools → Console）
```
