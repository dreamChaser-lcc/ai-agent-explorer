# SQL 基础实战 · 课程总纲

> **目标**：把 SQL 从"看得懂项目里的几条查询"练到"**能写、能改、知道为什么这么写**"——为 MyBatis 手写 SQL 主线（场景③ 起）和后续业务场景打地基。
> **方式**（沿用 Java 基础实战已验证的四段式）：**项目真实 SQL 为教材** + 前端视角类比 + 逐行拆解 + 动手在 H2 控制台验证。
> **教材来源**：全部取自本仓库真实代码——
> - `backend/src/main/resources/schema-dev.sql`（11 张真实表 + 索引）
> - `backend/src/main/resources/mapper/ResearchTaskMapper.xml`、`TaskEventLogMapper.xml`（项目在跑的手写 SQL）
> **验证环境**：dev 模式启动后，H2 控制台 `http://localhost:8080/h2-console`（JDBC URL `jdbc:h2:file:./data/h2db/research-agent;MODE=PostgreSQL;DATABASE_TO_LOWER=TRUE;DEFAULT_NULL_ORDERING=HIGH`，用户名 `sa`，密码空）——**每课都有现场验证，用证据说话**。
> **建立**：2026-10-15（用户决定：暂停业务场景主线，先补 SQL 基础，之后再回场景⑧）。

## 三、学习方式（课堂约定）

1. **每课一篇文档**（本文件夹内）——含"讲义 + 项目关联地图 + 动手练习"；
2. **上课流程**：通读讲义 → 逐点讲解（前端类比）→ **H2 控制台亲手跑练习** → 验证 → 文档勾选落档；
3. **教材优先取"项目在跑的 SQL"**——趁热打铁，学完立刻能读 mapper 里的每一条语句；
4. **配套速查**：`docs/SQL学习手册-CRUD与多表查询.md`（日常回顾用，课程是"精读版"）。

## 四、与 backend 项目的关联原则

- 每篇文档结尾都有「**项目关联地图**」：这些 SQL 在仓库里**哪里出现、怎么用**；
- **反向索引**：读 mapper XML 撞见看不懂的 SQL → 回查对应课程；找不到 → 就是下一课。
