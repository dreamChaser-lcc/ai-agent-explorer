## 四·补、水平定位与进阶路线（2026-10-18 学员提问"算入门还是初级中级，还有更进阶的吗"）

### 当前水平：应用开发视角的「初级偏上」，摸到中级门槛

| 等级 | 标志能力 |
|---|---|
| 入门 | 单表 CRUD、简单 WHERE / ORDER BY / LIMIT |
| 初级 | 多表 JOIN、聚合报表、事务基本用法、建表加索引 |
| **初级偏上（S1–S7 完成 ≈ 此处）** | 会看 EXPLAIN 判断走没走索引、知道索引失效条件、懂窗口函数、能写 CTE/递归、理解约束与 NULL 语义 |
| 中级 | 独立定位并优化慢查询（连接算法/统计信息）、懂隔离级别与锁并能排查死锁、能设计复合索引与深分页策略、懂 schema 演进与归档 |
| 高级 | 分库分表、读写分离、分布式事务、海量数据建模、容量规划 |

**最大短板不是知识，是数据量**：本项目库仅 15 行，性能实验均在 10000 行练习表上完成——真实慢查询/锁等待/索引膨胀要到百万行 + 并发才现形。

### 中级还差三块（按优先级）

1. **事务隔离与锁**（最大缺口）：MVCC、脏读/不可重复读/幻读、行锁/表锁、`SELECT ... FOR UPDATE`、死锁排查；
2. **查询优化进阶**：连接算法（Nested Loop / Hash Join / Merge Join）、`EXPLAIN ANALYZE` 耗时分析、统计信息（`ANALYZE`）导致计划突变；
3. **索引与分页工程**：复合索引设计（最左前缀 + 覆盖索引 + 索引下推）、`LIMIT 100000, 10` 深翻页为何慢 + keyset 分页。

### 进阶知识地图

- **第一层（后端必备，补完即中级）**：隔离级别与锁、连接算法与统计信息、复合/覆盖索引、深分页、upsert（`ON CONFLICT`/`MERGE`）、批量操作；
- **第二层（数据层工程）**：数据建模（范式 vs 反范式、宽表、星型模型、JSON 列边界）、schema 演进（Flyway/Liquibase，生产用 Flyway）、备份恢复与归档（场景⑩）；
- **第三层（规模化，了解即可）**：分库分表（ShardingSphere）、读写分离与主从延迟、分布式事务（2PC/Saga/本地消息表）、OLAP vs OLTP 与列存（ClickHouse/Doris）、ETL。

### 推荐路径：主线就是进阶课

| 主线场景 | 覆盖的进阶知识 |
|---|---|
| ⑨ 并发控制实验（DB 锁 vs Redis 锁） | **隔离级别、行锁、死锁——第一层缺口 1** |
| ⑩ 定时清理 | 归档与批处理——第二层 |
| ⑪ N+1 与懒加载 | ORM 的 SQL 生成与连接性能 |
| ⑫ 测试体系 | 工程化 |

### 四条自我检验（能独立做到 = 中级）

1. 给一条慢 SQL，能自己 `EXPLAIN` 定位并给出索引或改写方案；
2. 能讲清"两个事务同时 UPDATE 同一行会怎样"，并知道如何避免死锁；
3. 能设计复合索引并**验证**其被使用（而非凭感觉）；
4. 能解释"100 万行列表页第 1 页快、第 10000 页慢"，并给出改法。
