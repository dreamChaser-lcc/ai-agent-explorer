# Spring 基础实战 · 课程总纲

> **定位**：2026-10-21 应学员要求开线——"系统学习 Spring 基础，补齐后端知识的地基"。
> **关键认知**：这**不是从零学**。业务场景①-⑧ + 场景⑧延伸已经零散用过大量 Spring 特性，
> 这条线的价值是：**把零散的实战串成体系 + 补原理盲区 + 踩经典坑（失效场景/传播行为/自动配置）**。
> **学习方式**：沿用四段式（讲义落档 → 对话开讲带前端类比 → 项目真实代码为教材 → H2/接口现场验证），提问必落档双台账。
> **教材**：项目真实代码（research-agent）为主；廖雪峰 Java 教程"Spring 开发 / Spring Boot 开发"章节为课外阅读参照（学员提供的目录截图）。
> **状态**：🔄 持续更新（完成项打勾；新课结束后同步）

## 一、你已经接触过什么（盘点，避免重复学）

| Spring 能力 | 在项目/课程里接触过的地方 | 掌握程度 |
|---|---|---|
| IoC / 依赖注入 | J7 注解体系（"申请书+外包工"）、场景⑧ 构造器注入、`List<ResearchTool>` 集合注入 | 用过，原理没系统学 |
| AOP | 场景⑤ `@AuditLog` 审计切面 | 用过，没讲代理原理与失效场景 |
| 事务 | 场景②④ `@Transactional` + 乐观锁 | 用过，传播行为没学 |
| MVC + 全局异常 | 场景① `@RestControllerAdvice` + Bean Validation | 用过，DispatcherServlet 全流程没学 |
| 缓存 | 场景⑦ `@Cacheable` + Redis | 用过 |
| 配置绑定 | 场景⑧ `@ConfigurationProperties`（Q5 刚讲） | 刚入门 |
| 异步 | J8 `@Async` + 线程池 | 用过 |
| starter 自动装配 | 场景⑧ 讨论过"引 starter 就有 bean" | 概念有，机制没拆 |
| Actuator / 打包 | 部署面 K8s 探针、JAVA_OPTS | 用过，未系统化 |
| JPA / MyBatis | 项目双持久化模式切换 | 用过，分层关系没串 |

**结论**：这条线的每一课都是"**加深 + 补原理 + 踩坑**"，不是新课从零讲。

## 二、课程地图（10 课 · 三个模块）

### 模块一 · Spring Framework 核心（原理补齐）

| 课 | 主题 | 你已会 | 本次新学 / 补齐 | 项目素材 | 对标廖雪峰 |
|---|---|---|---|---|---|
| **SP1** | **IoC 容器与 Bean 生命周期** | 构造器注入、@Bean/@Component | 容器启动流程、Bean 定义与实例化两阶段、生命周期回调（@PostConstruct/@PreDestroy）、作用域、@Primary/@Qualifier、**循环依赖与三级缓存** | `LlmClientConfiguration`、`ResearchToolRegistry` | 22.1 |
| **SP2** | **AOP 与动态代理** | @AuditLog 切面、@Transactional 表面用法 | JDK 动态代理 vs CGLIB、切点表达式、五种通知、**AOP 失效场景（自调用最经典）** | 场景⑤ `AuditLogAspect` | 22.2 |
| **SP3** | **MVC 请求处理全流程** | Controller、参数校验、全局异常 | DispatcherServlet 流程、参数解析器背后、**Interceptor vs Filter vs AOP 对比矩阵**、内容协商 | `ResearchTaskController`、`ApiExceptionHandler` | 22.4 |
| **SP4** | **事务传播与失效场景** | @Transactional 基本用法、BEGIN/ROLLBACK | **七种传播行为**（REQUIRED/REQUIRES_NEW/NESTED 重点实验）、**失效四坑**（自调用/非 public/异常被吞/rollbackFor） | 场景②④ 事务代码 | 22.3 |

## 四、学习约定（沿用既有纪律）

1. **每课闭环**：讲义落档（`docs/Spring基础实战/SPx·主题.md`）→ 对话四段式开讲 → 项目代码/H2/接口现场验证 → 勾选本表 → git 提交（本地）；
2. **提问必落档（双台账）**：全局提问索引 + 每课文档自带「本课问答记录」；
3. **真实代码为教材**：每个概念都对应 research-agent 里的一段真实代码；
4. **遇卡即停**：场景线或其他课撞到 Spring 问题，随时插讲；
5. **学完回主线**：SP 线结束后回业务场景⑨（并发控制——正好用到 SP2 代理与 SP4 事务传播的理解）；
6. **★ 引用旧知识必须可回溯（2026-10-21 学员要求）**：讲义里提到"你已会 / 学过 X"时——① 必须带**相对文档链接**（`../Java基础实战/J7·注解体系.md` 这类）；② 同时在讲义内附**「前置知识速查」节**（旧知识的核心结论完整写入，不依赖跳转也能读懂）。**复习时不允许出现断链**。每课的速查节统一放在正文最前（§零）；
7. **★ 文件清单必须可点击，且"本地 + 云端"双兼容（2026-10-21 学员要求）**：每个源码文件给**两个链接**——文件名本身用相对链接（本地 IDE 跳转），后面跟 `[网页版]` 绝对链接（GitHub Pages 可用）：

```markdown
| [`TokenAuthFilter.java`](../../backend/src/main/java/com/aiexplorer/researchagent/infrastructure/web/TokenAuthFilter.java) [网页版](https://github.com/dreamChaser-lcc/ai-agent-explorer/blob/main/backend/src/main/java/com/aiexplorer/researchagent/infrastructure/web/TokenAuthFilter.java) | Token 鉴权 Filter |
```

| 链接 | 用在哪 | 原因 |
|---|---|---|
| **相对链接**（文件名本身） | 本地 IDE（CodeBuddy / VS Code / IDEA） | 点击直接跳转源文件（md 在 `docs/Spring基础实战/`，到仓库根要 `../../`） |
| **`[网页版]` 绝对链接** | GitHub Pages | **Jekyll 会把 `.java` 渲染成 `.java.html`，且路径规则不同——相对链接在 Pages 上必然 404** |

> 仓库坐标：`dreamChaser-lcc/ai-agent-explorer`，分支 `main`。若仓库改名/换分支，`[网页版]` 链接需批量更新（正则替换即可）。

8. **★ 思考题必须"问题/答案分行"（2026-10-21 学员要求）**：有序列表内的普通换行会被 Markdown 当成**软换行**（合并成一段），问题和答案会挤在一起。写法——**问题行末尾加 `<br>`**：

```markdown
1. 为什么连接池不是越大越好？<br>
   **参考答案**：……
```

> `<br>` 是 HTML 硬换行，所有渲染器（IDE 预览 / GitHub / Typora）都生效；行尾两个空格的写法在部分编辑器会被自动去除，不如 `<br>` 稳定。
