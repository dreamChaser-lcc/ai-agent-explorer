## 当前可运行方式

### 后端

```powershell
cd D:\Project\ai-agent-explorer\backend
mvn spring-boot:run "-Dspring-boot.run.profiles=dev"
```

### 前端

```powershell
cd D:\Project\ai-agent-explorer\frontend
npm run dev
```
