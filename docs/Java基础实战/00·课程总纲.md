## 二、学习方式（课堂约定）

1. **每课一篇文档**（本文件夹内）——含"讲义 + 项目关联地图 + 动手练习"；
2. **上课流程**：通读讲义 → 逐点讲解（前端类比）→ **动手改一小段代码** → 验证 → 文档勾选落档；
3. **教材优先取"你改过 / 见过的代码"**——趁热打铁，学完立刻能用在项目里。

## 三、与 backend 项目的关联原则

- 每篇文档结尾都有「**项目关联地图**」：这些语法在仓库里**哪里出现、怎么用**；
- **反向索引**：开发中撞见看不懂的语法 → 回查对应课程；找不到 → 就是下一课。
