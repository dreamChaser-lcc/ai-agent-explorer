## 一、为什么单独开一条 line（与 SP 线的分工）

| 维度 | Spring基础实战（SP1–SP11） | SpringBoot实战（SB1–SB8） |
|---|---|---|
| 讲什么 | **框架原理**：IoC/AOP/MVC/事务/启动流程/Filter/数据访问 | **Boot 工程化**：自动配置扩展/Starter/配置优先级/部署/可观测/测试/版本特性 |
| 侧重 | "框架是怎么工作的" | "怎么把 Boot 用到生产" |
| 例子 | SP5 讲启动流程 | SB1 讲**怎么读/写**自动配置（`@Conditional` 家族） |
| 重复度 | — | **不重复**：只补 Boot 特有能力（见下方"已覆盖对照"） |

## 二、课程清单（8 课）

| # | 课 | 内容 | 状态 |
|---|---|---|---|
| SB1 | 自动配置原理深入 | `@EnableAutoConfiguration` 的装配链 / `AutoConfiguration.imports` / `@Conditional` 家族（`@ConditionalOnBean/Class/MissingBean/Property/WebApplication`）/ 条件装配顺序与调试（`--debug` 的 condition report） | ⬜ |
| SB2 | 自定义 Starter | Starter 的两层结构（autoconfigure + starter）/ `spring.factories` → `AutoConfiguration.imports` 迁移 / 手写一个 `research-agent-starter`（自动配置类 + 属性类 + 条件装配 + 最小 Spring Boot 测试） | ⬜ |
| SB3 | 外部化配置优先级 | 17 种配置源优先级矩阵（命令行 > 环境变量 > 系统属性 > 配置文件 > 默认值）/ Profile 组合与 `spring.config.import` / 配置加密（jasypt 或环境变量注入）/ 本项目 `start.ps1` 的 env 注入属于哪一层 | ⬜ |
| SB4 | 内嵌容器与部署 | Tomcat 调优（线程池/连接数/压缩）/ 优雅停机（`server.shutdown=graceful` + `spring.lifecycle.timeout-per-shutdown-phase`）/ 启动加速（懒初始化/AOT/CDS）/ Undertow 对比 / 容器化部署（Dockerfile 多阶段） | ⬜ |
| SB5 | Actuator + Micrometer 可观测性 | 端点全解 / enabled vs exposure / Micrometer 四类指标 / Prometheus+Grafana / 探针分组 | ✅ 2026-11-26（实测：demo.hits COUNT=3 / jvm.memory 115MB / http.server.requests 8 次） |
| SB6 | 测试体系 | `@SpringBootTest` vs 切片测试（`@WebMvcTest`/`@DataJpaTest`/`@JsonTest`）/ MockMvc / `@MockBean` 与 `@MockitoBean`（3.x 变更）/ Testcontainers（PG/Redis/Kafka 真实容器）/ 测试分层策略（单测/切片/集成） | ⬜ |
| SB7 | Boot 3 新特性 | Jakarta EE 9+ 迁移（`javax.*` → `jakarta.*`）/ 虚拟线程（`spring.threads.virtual.enabled=true`）/ GraalVM Native Image 与 AOT / Problem Details（RFC 9457 错误响应）/ Observability 统一（Micrometer Tracing） | ⬜ |
| SB8 | 生产化 Checklist | 启动/内存/线程池/连接池/HTTP 客户端/超时（连接/读/写）/ 日志（结构化 + MDC traceId）/ 健康检查与优雅下线/配置安全/资源限制——**上线前逐项打勾** | ⬜ |

## 三、学习路径（四阶段）

```text
阶段 1（原理与扩展）：SB1 自动配置深入 → SB2 自定义 Starter
  产出：看懂任何 starter 的自动配置；手写一个自己的 starter
阶段 2（配置与运行）：SB3 配置优先级 → SB4 内嵌容器与部署
  产出：说清"这个配置从哪来的"；配好优雅停机与容器化部署
阶段 3（可观测与测试）：SB5 Actuator+Micrometer → SB6 测试体系
  产出：/actuator/prometheus 出指标；切片测试替代一整锅 @SpringBootTest
阶段 4（版本与生产）：SB7 Boot 3 新特性 → SB8 生产化 Checklist
  产出：虚拟线程实验 + 上线前检查清单
```

## 七、一句话

```text
Spring = 框架（告诉你"能做什么"）；Spring Boot = 工程化（告诉你"怎么省事地用"）。
SP 线学完 ≠ Boot 学完——Boot 的省事背后（自动配置/Starter/配置优先级/部署/可观测）
恰恰是排障和扩展时最该懂的部分。
```
