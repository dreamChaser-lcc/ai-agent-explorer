## 二、后端内功实战清单（业务驱动 · 主轴）

### 2.1 内功四层（前端 → 后端的缺口地图）

| 层 | 内容 | 自评 | 主要载体 |
|----|------|------|---------|
| **L1 Java 语言** | 集合 / Stream / 泛型 / 并发 / 异常体系 / JVM 常识 | 写业务够用；**并发与 JVM 待补** | 场景中随时补 |
| **L2 Spring 应用** | IoC / Bean 生命周期 / 事务传播 / AOP / MVC / 校验 | starter 会用；**原理待补** | 场景 ①②⑤ |
| **L3 数据** | SQL / 索引 / 事务隔离 / 连接池 / 缓存策略 | **重点待补** | 场景 ③④⑦⑪ |
| **L4 分布式业务** | 幂等 / 锁 / 一致性 / 异步 / 重试补偿 | 组件学过；**实战缺** | 场景 ⑥⑧⑨⑩ |

### 2.2 业务场景清单（research-agent 为载体，逐项开课）

> 每项均可独立开一课：**设计 → 编码 → 部署 → 验证 → 落档**（沿用既有学习模式）。

| # | 场景 | 带出的后端知识 | 状态 |
|---|------|--------------|------|

| ② | **任务状态机**：`WAITING → RUNNING → DONE` 流转（状态模式 + 事务 + 乐观锁） | 事务边界、并发控制 | ⬜ |

| ⑤ | **AOP 实操**：操作审计日志（谁、何时、改了什么） | AOP（**前端"装饰器"的后端版**） | ⬜ |

| ⑧ | **下游调用治理**：LLM 调用的超时 / 重试 / 降级（Resilience4j 或 Sentinel） | 容错模式、重试语义 | ⬜ |

| ⑩ | **定时清理**：过期任务归档（`@Scheduled` → 分布式调度概念） | 调度、批处理 | ⬜ |
| ⑪ | **N+1 与懒加载**：关联查询的坑与解法（ORM 原理） | ORM、SQL 生成 | ⬜ |

## 四、学习原则（交错，不排队）

1. **主轴 = 业务场景**（第二章）：每课 = 一个真实场景的完整闭环——业务驱动，知识在"用"中学；
2. **加固 = 按需**（第三章）：业务撞上基础设施需求时，**在需要它的那一刻**翻清单开课（例：场景 ⑥ → G1）；
3. **部署面的积累不浪费**：它是"按需调用"的库——遇到架构问题时回头看，会发现大部分手艺已经学过；
4. 沿用惯例：**一课一闭环、文档落档、里程碑 tag**；
5. ★ **每课收尾固定动作（2026-10-03 约定）**：验证通关 → 落档（复盘文档 + memory + **本清单勾选**）→ **提醒提交 git**（Conventional Commits + 中文，按惯例拆分）→（里程碑时）打 tag。
